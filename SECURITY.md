# Security policy

## Report a vulnerability

Use **Report a vulnerability** on the [upstream GitHub security page](https://github.com/thehamkercat/WilliamButcherBot/security/advisories). If the button is unavailable, open an upstream issue asking for a private reporting channel. Keep vulnerability details out of public issues, pull requests, and Telegram chats.

Include the affected version or commit, the configuration needed to trigger the issue, its impact, and steps to verify it. Remove credentials, bot tokens, and personal data from examples and logs.

## Coordinated disclosure

We review reports privately and coordinate publication with the reporter. When a fix is ready, we publish a GitHub Security Advisory with the affected versions or commits, the fixed commit, and update instructions. If operators need to act before a fix is ready, we publish available mitigation steps.

## Fork maintainers and bot operators

Check the [upstream security advisories](https://github.com/thehamkercat/WilliamButcherBot/security/advisories) for updates. If your fork is affected, merge or backport the fix. If you run a bot, redeploy it with the patched code and verify that the running instance uses the fixed revision.
